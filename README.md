# A Letter to God — 20 Important MCQs

Class 10 English (First Flight), Chapter 1.

## What is included?
- 20 interactive MCQs
- Instant score
- Correct/wrong highlighting
- Explanations after submission
- Mobile-friendly design
- Single `index.html` file, so no server/database is required

## Important source note
The quiz uses documented CBSE MCQ material and recurring previous-year/board-exam topics. It does NOT claim that every question appeared verbatim in a CBSE board paper.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Open Settings → Pages.
4. Under Build and deployment, select `Deploy from a branch`.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will generate your Pages link.

The site is fully static, so it can run directly on GitHub Pages.
